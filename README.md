Actividad Semana 1
Creando una estructura básica en HTML

---

Descripción

Página web para una tienda de videojuegos llamada ZonaGame, desarrollada como parte de la actividad formativa de la semana 1.

La página utiliza etiquetas semánticas HTML:
- `<header>` para la cabecera
- `<nav>` para el menú de navegación
- `<section>` para los productos destacados
- `<footer>` para el pie de página

---

Requisitos cumplidos


| Encabezados `<h1>`, `<h2>`, `<h3>` 
| Párrafos `<p>` con descripciones 
| Listas `<ul>` para menú y productos 
| Enlaces `<a>` en el menú de navegación 
| Imágenes `<img>` en cada producto 
| Etiquetas semánticas
